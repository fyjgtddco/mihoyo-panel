# 米游社面板插件 (miyoyo_panel)

AstrBot 插件，支持**原神 / 崩铁 / 绝区零**三个游戏的玩家面板查询。
全部走纯指令触发，**不经过 AI**，结果以图片形式返回。

数据来源：[Enka Network](https://enka.network)（公开的展示柜数据接口）

---

## 功能

### 面板查询
| 指令 | 说明 |
|---|---|
| `/绑定原神 <UID>` | 绑定原神 UID（9 位） |
| `/绑定崩铁 <UID>` | 绑定崩铁 UID（9 位） |
| `/绑定绝区零 <UID>` | 绑定绝区零 UID（8 位） |
| `/绑定uid <UID>` | 自动识别是哪个游戏的 UID |
| `/原神面板` | 角色列表图（一屏概览） |
| `/原神面板 兹白` | 单个角色详情大图 |
| `/崩铁面板` / `/绝区零面板` | 同上，支持带角色名 |
| `/更新面板` | 强制刷新，换一张新图 |
| `/我的uid` / `/解绑uid` | 查看 / 解除绑定 |

### 圣遗物
| 指令 | 说明 |
|---|---|
| `/圣遗物` | 原神圣遗物列表（5 列网格，逐件评分） |
| `/遗器` | 崩铁遗器列表 |
| `/驱动盘` | 绝区零驱动盘列表 |
| `/圣遗物 第2页` | 分页查看 |
| `/圣遗物排行` | 群内圣遗物得分排行榜 |
| `/遗器排行` / `/驱动盘排行` | 同上 |
| `/圣遗物总榜` | 三个游戏合并排行 |

### 其他
| 指令 | 说明 |
|---|---|
| `/战绩` | 原神深渊战绩（深境螺旋 / 幻想真境剧诗） |
| `/伤害 兹白` | 角色伤害计算（含计算过程） |
| `/对比 兹白 桑多涅` | 角色属性对比 |
| `/养成周报` | 与上次快照对比的变化 |
| `/角色收集排行` | 群内角色收集度排行 |
| `/动态面板` | 滚动动画（GIF） |

## 评分规则

圣遗物评分按各游戏**社区通用规则**：

- **原神 / 崩铁**：双暴分法 —— `暴击率 × 2 + 暴击伤害 × 1`
  - 40 分 = 毕业
  - 50 分 = 极品
  - 理论极限约 54.6 分
- **绝区零**：单件满分 55 分（工坊口径），全套满分 330

## 安装

1. 把本仓库所有文件放到 `AstrBot/data/plugins/miyoyo_panel/` 目录下
2. 在 AstrBot WebUI 中重载插件，或重启 AstrBot
3. 首次启动会自动下载并缓存游戏的名称/属性映射表（约 3MB，缓存 7 天）

### 依赖

插件依赖 AstrBot 内置的 `aiohttp` 和 `Pillow`，无需额外安装。

```
aiohttp
Pillow
```

---

## 配置项

在 AstrBot WebUI 的插件配置中可调整：

| 配置 | 默认 | 说明 |
|---|---|---|
| `cache_ttl` | 180 | 图片缓存时长（秒） |
| `cooldown` | 3 | 同一用户同一游戏的冷却（秒） |
| `max_characters` | 12 | 角色列表图最多显示几个角色 |

## 说明与限制

**关于数据**
- 原神的面板属性是 enka 计算好的**最终数值**，准确
- 崩铁 / 绝区零的面板属性是**本地估算**（enka 只给装备数据），图上已标注
- 需要在游戏内打开「显示角色详情 / 展示柜」，否则查不到数据

**关于战绩**
- 仅原神能拿到真实战绩（深境螺旋 / 幻想真境剧诗），因为 enka 提供了这两个字段
- 崩铁 / 绝区零的战绩需要米游社登录凭证，本插件不收集用户 Cookie，因此不提供

**关于上游稳定性**
- enka.network 偶有波动（返回 424 维护 / 500 等），插件已做重试和友好提示

```
├── zzz.py             绝区零：解析 + 渲染
├── metadata.yaml      插件元数据
└── _conf_schema.json  配置schema
```
