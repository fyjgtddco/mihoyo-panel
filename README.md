# 米哈游角色面板查询插件 (mihoyo_panel)

AstrBot v4.26.8 插件，支持查询**原神**、**星穹铁道**、**绝区零**的角色详细面板，以图片形式展示。

## 功能特性

- 绑定/解绑游戏 UID（按群聊+用户独立存储）
- 查询角色展柜面板，自动生成精美角色卡片
- 卡片包含：角色立绘、等级、命座、行迹、专武、基础属性、圣遗物/遗器/驱动盘详情
- 支持 HTTP 代理，方便国内网络访问 Enka API
- 自动下载本地化数据和中文思源黑体，首次启动无需手动配置

## 指令说明

| 指令 | 说明 | 示例 |
|------|------|------|
| `/原神 <UID>` | 绑定原神 UID | `/原神 618285856` |
| `/星铁 <UID>` | 绑定星穹铁道 UID | `/星铁 843715177` |
| `/崩铁 <UID>` | 同上（别名） | `/崩铁 843715177` |
| `/绝区零 <UID>` | 绑定绝区零 UID | `/绝区零 123456` |
| `/查询原神面板` | 查询已绑定 UID 的原神角色面板 | `/查询原神面板` |
| `/查询星铁面板` | 查询已绑定 UID 的星铁角色面板 | `/查询星铁面板` |
| `/查询崩铁面板` | 同上（别名） | `/查询崩铁面板` |
| `/查询绝区零面板` | 查询已绑定 UID 的绝区零角色面板 | `/查询绝区零面板` |
| `/解绑原神` | 解绑原神 UID | `/解绑原神` |
| `/解绑星铁` | 解绑星穹铁道 UID | `/解绑星铁` |
| `/解绑崩铁` | 同上（别名） | `/解绑崩铁` |
| `/解绑绝区零` | 解绑绝区零 UID | `/解绑绝区零` |

> ⚠️ 被查询的账号需要在游戏内开启角色展柜「显示角色详情」，否则 API 无法返回数据。

## 插件配置

插件安装后，可在 AstrBot 后台的插件配置中设置：

| 配置项 | 类型 | 说明 | 默认值 |
|--------|------|------|--------|
| `proxy` | string | HTTP 代理地址，如 `http://127.0.0.1:7890` | 留空（直连） |

## 首次运行

插件首次加载时会自动下载以下资源，请耐心等待片刻：

1. **静态数据**：角色名、武器名、圣遗物名等本地化文件（从 Enka-docs GitHub 仓库下载）
2. **思源黑体**：用于图片中文渲染，自动下载至插件数据目录

下载完成后即可正常使用。

## 依赖

- Python 3.8+
- aiohttp
- Pillow

插件安装时会自动安装依赖。

## 数据来源

角色面板数据来自 [Enka.Network](https://enka.network/)，感谢他们的开放 API。
